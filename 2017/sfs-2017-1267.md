# Förordning om ränta på lån till hemutrustning för flyktingar och vissa andra utlänningar för 2018

## 1 §

Den ränta som ska betalas på lån till hemutrustning enligt [16 §](#16) första stycket förordningen ([1990:1361](https://selex.se/eli/sfs/1990/1361)) om lån till hemutrustning för flyktingar och vissa andra utlänningar ska vara 1,7 procent för 2018.
