# Förordning om tidsbegränsning av anställning av personal vid Europaskolorna

Statens skolverk får anställa personal för bestämd tid eller tills vidare längst till viss tidpunkt om anställningen gäller tjänstgöring vid en skola som inrättats för barn till personalen vid Europeiska gemenskaperna (Europaskola). Förordning ([1996:371](https://selex.se/eli/sfs/1996/371)).
