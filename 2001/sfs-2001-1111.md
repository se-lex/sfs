# Lag om särskild bestämmelse om bostadsbidrag

För år 2002 lämnas bostadsbidrag enligt lagen ([1993:737](https://selex.se/eli/sfs/1993/737)) om bostadsbidrag med följande avvikelse.

Vid beräkning av den bidragsgrundande inkomsten enligt [4 §](#4) skall studiebidrag enligt studiestödslagen ([1999:1395](https://selex.se/eli/sfs/1999/1395)) ingå med 80 procent.
