# Förordning om ersättning enligt lagen om statlig ersättning vid ideell skada m.m.

Regeringen föreskriver att ersättning enligt lagen ([1977:266](https://selex.se/eli/sfs/1977/266)) om statlig ersättning vid ideell skada m.m. beslutas och betalas ut av Kammarkollegiet.
