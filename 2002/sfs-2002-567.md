# Förordning om upphävande av vissa förordningar rörande sanktioner mot "Förbundsrepubliken Jugoslavien" (Serbien-Montenegro)

Regeringen föreskriver att följande förordningar skall upphöra att gälla vid utgången av juni 2002:

1. förordningen ([1993:665](https://selex.se/eli/sfs/1993/665)) om tillämpning i fråga om "Förbundsrepubliken Jugoslavien" (Serbien-Montenegro) av lagen ([1971:176](https://selex.se/eli/sfs/1971/176)) om vissa internationella sanktioner, och

2. förordningen ([1994:1668](https://selex.se/eli/sfs/1994/1668)) om vissa sanktioner mot "Förbundsrepubliken Jugoslavien" (Serbien-Montenegro).
