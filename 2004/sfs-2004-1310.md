# Förordning om ränta på återbetalning enligt lagen om underhållsstöd för år 2005

Regeringen föreskriver att den ränta som enligt [36 §](#36) lagen ([1996:1030](https://selex.se/eli/sfs/1996/1030)) om underhållsstöd skall betalas på skuld som avser återbetalningsskyldighet enligt samma lag skall vara 2,8 procent för år 2005.
