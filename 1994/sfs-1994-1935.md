# Förordning om upphävande av vissa författningar om ställföreträdare för kommun vid vissa förhandlingar m.m.

Regeringen föreskriver att följande författningar skall upphöra att gälla vid utgången av år 1994, nämligen

1. kungörelsen ([1965:577](https://selex.se/eli/sfs/1965/577)) med tillämpningsföreskrifter till lagen om ställföreträdare för kommun vid vissa avtalsförhandlingar m.m.,

2. förordningen ([1976:1064](https://selex.se/eli/sfs/1976/1064)) om ställföreträdare för kommun vid vissa förhandlingar, m. m.
